# The dependencies needed to **run the tests**, as opposed to the
# dependencies needed to **run the system**.
#
# The runtime dependency of the submitted system is numpy, and nothing
# else - that is what ``requirements.txt`` says, and it is correct: the
# image is built from ``python:3.12-slim-bookworm`` and the three-track
# closed loop (tracks/, rulkit/, harness/) runs on numpy alone.
#
# The test suite is a different matter.  Several test modules import
# ``pytest`` at module scope and use its fixtures, ``parametrize``
# marks and ``approx``/``raises`` helpers, so a runner that installs
# only ``requirements.txt`` cannot even **import** the suite: it fails
# at collection, at ``import pytest`` - before a single assertion runs.
#
# The rest of this file is the ``evo`` extra from ``pyproject.toml``.
# ``evo`` is the legacy implementation, kept for comparison and not on
# the path of the submitted system, but ``tests/test_core.py`` and
# ``tests/test_sample_weight.py`` import it at module scope - so
# without these the suite fails at collection there too.
#
#   python -m pip install -r requirements.txt -r requirements-dev.txt
#
# ``requirements-dev.txt`` never enters the image: the image installs
# ``requirements.txt`` alone.
