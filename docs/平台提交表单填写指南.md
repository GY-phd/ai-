> 选基础模型只需要再点一次确认即可，选 Sampler 则必须先有一个真实的 `trio://` 权重路径。

### 2. 模型 / 权重路径

- **选「基础模型」**时：这是一个**下拉框**，选项来自平台后端的
  `rules.allowed_models`（只显示不含 `://` 的条目）。**从下拉里选一个即可，不要手打。**
- **选「持久化 Sampler」**时：粘贴 PyTRiO `save_weights_for_sampler()` 返回的完整路径。

平台对 `trio://` 的校验规则（前端源码原文）：

```js
let e = new URL(r);
if (e.protocol !== 'trio:' || !e.hostname || e.username || e.password ||
    e.search || e.hash || /\s/.test(r)) throw Error()
```

翻译成人话，路径必须满足：

| 要求 | 说明 |
| --- | --- |
| 协议是 `trio:` | 不能是 `https://`、不能是本地路径 |
| 有 hostname | `trio://` 后面必须有主机名段 |
| **不能有用户名** | `trio://user@host/...` 会被拒 |
| **不能有密码** | 同上 |
| **不能有 query** | 不能带 `?a=b` |
| **不能有 fragment** | 不能带 `#frag` |
| **不能有空格** | 任何空白字符都不行 |

平台给出的错误提示原文：

> 请粘贴 PyTRiO 保存后返回的完整 `trio://` Sampler 权重路径，
> **不要填写基础模型名、训练ID或本机路径**。

**完整路径的来源**：在 PyTRiO 上微调完模型后调用 `save_weights_for_sampler()`，
它返回一个 `trio://` 开头的字符串，**原样粘贴**。它不在本仓库里，
也不在镜像里——镜像只负责运行 SDK 协议，模型访问由平台通过
`model_access: host_gateway_rpc` 代持。

#### 选 4B 还是 27B？——**默认 `Qwen/Qwen3.8-27B`，4B 作为降级备选**

这是本次整改中最容易走错的一步，用实测数据说清楚。

**先说结论：分数与这个选择无关。** 平台的评分是拿你的**工业模型**在
`hidden_test` 上算 `macro_f1` / `rmse`，LLM 的输出只被写进实验记录的
`reason` 字段，用来证明"这一轮做了真实推理"。**LLM 的大小不进入任何
一个分数项。** 所以"27B 更聪明 → 分数更高"这个直觉在这里是错的。

**再说实测：27B 在默认配置下会把这一轮直接搞挂。**

用**训练循环真实发出的那条 prompt**（`contest_baselines/train.py::_model_brief`）
去调 PyTRiO，`max_tokens=512`（原代码的取值）：

| 模型 | 思维链 | 延迟 | `finish_reason` | 返回正文 |
| --- | --- | --- | --- | --- |
| `Qwen/Qwen3.5-4B` | 开 | **3.8 s** | `length` | **空** |
| `Qwen/Qwen3.8-27B` | 开 | **288.3 s** | `length` | **空** |
| `Qwen/Qwen3.5-4B` | 关 | 9.0 s | `stop`/`length` | 842 字符 |
| `Qwen/Qwen3.8-27B` | 关 | 12.0 s | `stop` | 793 字符 |

三个关键事实：

1. **两个模型默认都开思维链**，512 token 全被推理过程吃掉，`content` 是空的，
   `finish_reason` 是 `length`。
2. **27B 的思维链慢到离谱**——288 秒。平台的网关等不到这个响应，
   就报「**模型服务暂不可用，请稍后重试**」，这正是上一版镜像试运行失败的
   直接原因（**不是**余额问题，余额充足时同一个 Key 连续 6 次调用全部 HTTP 200）。
3. **关掉思维链后，两个模型都快**（9–12 秒），都返回实质正文，质量差别不大。

**所以本镜像的修法是代码层面的，与你选哪个模型无关：**

| 改动 | 位置 |
| --- | --- |
| 关闭思维链（`enable_thinking=False`） | `contest_baselines/train.py::_call_model` |
| token 预算 512 → **1024** | 同上（`_MODEL_TOKEN_BUDGET`） |
| 模型调用加**重试回退**（3 次，间隔递增） | 同上 |

> `enable_thinking` 是官方 SDK 白名单里的合法参数
> （`contest_harness/round.py::_MODEL_OPTIONS`），宿主不认识时会退回不带该参数重试，
> 所以这一改动不会让调用被拒。

**最终建议：**

- **默认选 `Qwen/Qwen3.8-27B`**。赛题要求驱动 Harness 的大模型是千问
  27B / 4B，27B 是更"正统"的那个；而且**代码层面已经修好了 27B 的坑**
  （关思维链 + 1024 token 预算 + 3 次重试），实测 27B 关思维链只要
  **12.0 秒**，与 4B 的 9.0 秒同量级。
- **`Qwen/Qwen3.5-4B` 作为降级备选**：如果试运行时 27B 仍然报
  「模型服务暂不可用」（平台侧排队、额度、并发等非代码因素），
  换 4B 立刻能跑通，且**不影响分数**。
- **两个模型都别再带思维链跑**——那才是真正会触发「模型服务暂不可用」的配置。

> **模型名的两种写法**：平台的下拉框里是 `Qwen/Qwen3.8-27B`（**斜杠**），
> 赛题正文和本仓库的配置里是 `Qwen3.8-27B`（**点**）。填表单时**从下拉框里选，
> 不要手打**；代码侧由 `harness/llm.py::resolve_model_id` 把短写法映射成
> 平台写法，两种拼法都能工作。

#### 这个 Key 从哪来

PyTRiO 不是一个公开的静态白名单——**Key 是你自己账号的**，去 PyTRiO 控制台现拿：

#### 这个 Key 必须满足什么

- 能访问并调用你填的**权重或基础模型**
- **有可用额度**（平台的确认文案原文：*"API Key 有权访问并有可用额度"*）
- 至少 8 个字符（平台前端 `minLength: 8` 校验）
- 权限是「组织」级的：PyTRiO 的 API Key 属于 **workspace（组织）**，
  不是个人账号。所以要先进一个工作空间再创建 Key；
  页面报错 *"当前登录会话缺少工作空间，请重新登录并重试"* 就是这个意思

#### 和本项目镜像的关系

**镜像里没有、也不该有这个 Key。** 本项目的 `tools/scan_for_secrets.py`
每次都会扫一遍运行时代码，结果是空的。平台在调用时通过宿主的
`model_access: host_gateway_rpc` 把访问权注入，选手代码只调 `rnd.model()`。

> SDK 使用文档原文：**「密钥、真实端点和计费由平台持有，不要把 PyTRiO 密钥
> 或外部采样客户端放进镜像。」** 也就是说，正式评测时的推理调用走的是
> 平台自己的网关节奏，**不是**你的 PyTRiO 账号余额。

> 本机环境变量里目前**没有** `PYTRIO_API_KEY`（我查过了）。如果之后你要在本地
> 跑 SDK 的真实模型测试（`tests/test_live.py`），才需要设这个变量：
> ```powershell
> $env:PYTRIO_API_KEY = "<你的 Key>"
> ```
> 注意 `test_live.py` **会产生真实费用**，而且本地训练一次平台不认。

#### ⚠️ 额度：Key 有权限 ≠ 有余额

平台表单的二次确认文案要求「API Key **有权访问并有可用额度**」。
这两件事是分开的：

| 检查项 | 结果 |
| --- | --- |
| Key 能鉴权（`GET /api/models`） | ✅ 通过 |
| Key 能调用所选基础模型 | ⚠️ **取决于余额** |

实测：**PyTRiO 工作空间余额为 0 时**，即使 Key 完全有效，推理调用也会返回

```
HTTP 409  {"error":{"message":"billing insufficient balance",
                     "type":"invalid_request_error",
                     "code":"insufficient_quota"}}
```

注意这个 409 **不是**权限问题，而是计费问题——所以它**无法**用来判断
「模型名填对没有」。两个模型（`Qwen/Qwen3.5-4B`、`Qwen/Qwen3.8-27B`）
和一个故意写错的模型名，返回的都是同一个 409。

**充值入口**：<https://pytrio.com/billing/recharge>（最低 ¥10，支付宝）。
或者向赛题组/指导老师索取代金券（Vouchers 标签页可兑换）。
在余额到账前，**本地任何真实模型调用都会失败**，离线演练不受影响。

## 五、选 Sampler 时的 `trio://` 完整路径从哪来

只有在你**确实做过微调并保存过权重**时才需要。它来自 PyTRiO，**不在本仓库里、
也不在镜像里**——镜像只负责跑 SDK 协议，模型访问由平台通过
`model_access: host_gateway_rpc` 代持。
