## 1. 方案摘要

本项目交付的不是单个模型，而是一个能在 **4 核 / 8G、无 GPU、离线** 环境中
无人干预跑完 10 轮的 Harness：

- **Harness 镜像**：唯一入口 `python3 /app/harness.py describe|train|predict`；
- **工业模型**：A/B/C 三个方向的 CPU MLP，从平台检查点续训，是平台的评分对象；
- **决策层大模型**：PyTRiO 上的 `Qwen3.8-27B` LoRA SFT Sampler，只负责提假设和
  动作建议，不直接改模型、不直接改门控；
- **证据链**：每轮写 ledger（哈希链）、SwanLab 指标流、四段式
  “读历史→提假设→做实验→做决策”记录。

C 方向的最终工业模型采用**相对退化度的样本加权**：
`w = 1 + α·(1 − RUL / 发动机寿命)`（α = 0.5），量纲无关，
对长寿命发动机不再把中段误判为寿命末期；选型判决**只看全量验证 RMSE**，
`late_rmse` 等截断切片降级为**纯记录**（不再否决改进或挽救退化），
全量验证 RMSE 另作 **5%** 安全 guard。

> ⚠️ **2026-11-24 根因结论（取代 2026-11-23 的并列判据）。**
> 上一版用的是**并列**判据（全量不劣化**且**协议对齐切片改善）。
> 12 折留一轴承实验（`research/tracks/c_horizon.py`）证明**任何**截断切片
> 与留出集真值都**负相关**（`y <= 50` 到 `y <= 200`，Spearman −0.27 ~ −0.53），
> 按切片选型在 12 折里选出**垫底**候选、**0 折**赢基线；
> 全量口径平均第 1 名、**7 折**赢基线。
> **这才是隐藏分 56.25329（比基线 52.8686 差 6.40%）的成因** ——
> 不是"公开集到隐藏集的口径偏移"，而是"用反向指标选型"这个动作本身。
>
> 完整证据与代码改动见 `docs/SELECTION_SLICE_ROOT_CAUSE_20261124.md`。
>
> 修复后的离线 10 轮演练：C 52.8686 → **51.3422**（第 10 轮 50.6314）、
> A 0.7140 → **0.7410**、B 681.16 → **456.42**。
>
> 历史记录（2026-11-23 平台试运行 v6）：新代码确实上线了
> （逐轮记录里出现了 `selection_metric`、`selection_before/after` 与
> `selection_guard`），但隐藏测试指标与上一版逐位相同（C 仍是 **56.25329**）。
> 当时归因为「公开集→隐藏集 +10.06% 偏移」，现已被上面的根因分析取代。
>
> 另修：C 方向 `profile_c.py` 缺 `import numpy`（会直接崩）；
> B 方向寿命估计由逐点比值 `t/(1-f)`（Jensen 不等式系统性偏低）
> 改为按 `t = N·(1-f)` 做最小二乘拟合。

## 2. 系统怎么运行

### 2.1 平台调用链

```text
平台 ──describe/train/predict──> /app/harness.py
                                  └─> contest_submission.py
                                      └─> contest_baselines/（A/B/C 适配器）
```

平台按数据集跑 10 轮。每轮传入父检查点、公开训练/验证投影和预算；
Harness 训练一个候选、在公开验证集上测量、决定采纳或保留父模型；
采纳的候选成为下一轮父模型。10 轮结束后，平台用最终 checkpoint 在
**隐藏测试集**上评分。

### 2.2 单轮闭环

1. `open_parent`：读取父检查点，校验 task 和 digest；
2. `read_public`：读训练/验证集，检查 ID 不重叠；
3. `plan`：从该数据集的假设库中选一个可证伪的假设；
4. `measure_parent`：在验证集上测父模型（C 同时测 `late_rmse`）；
5. `build_candidate`：复制权重/Adam/epoch，只改训练过程，训练候选；
6. `measure_candidate`：同一验证集、同一口径测候选；
7. `decide`：用 `late_rmse` 判决，C 再加 **5% full-split 并列 guard**；
8. `record`：写 ledger、SwanLab、review brief；
9. `consult_the_model`：PyTRiO 采样器复核；不可达时回落确定性策略；
10. `submit`：采纳则提交候选目录，拒绝则保留父模型。

### 2.3 资源与兜底

- 4 核 / 8G / 无 GPU / 断网；镜像约 263 MiB；
- 实验次数、墙钟、训练秒数、token 均有硬预算，超限降级 `do_nothing`；
- 大模型不可达 / 配额不足 / 返回空正文时，`harness/llm.py` 回落确定性策略，
  闭环照常完成；
- 参考加载器兼容：`contest.cpu-mlp.v1`，hidden ≤ 128，tanh，24 维输入，
  不打包任何模型权重。

## 3. C 方向：为什么加权，怎么加权

### 3.1 口径差异

公开验证集是完整寿命序列的每一行（RUL 0–500+）；隐藏测试是官方 C-MAPSS
截断协议，每台发动机只在最后观测周期出一行（公开测试 RUL 最大约 195）。
用公开**全量** RMSE 选型，会系统性地拒绝真正改善隐藏晚期指标的模型。

### 3.2 代理口径

在公开验证集上，对每台发动机按公开 C-MAPSS 测试 RUL 分布抽一个截断周期 `h`，
取 `last_cycle - h` 那一行，按隐藏测试发动机数加权，得到 `cmapss_proxy`。
另用 `uniform_protocol`（每台均匀抽 0–200）和 `late_rmse`（RUL ≤ 200 的行）
作为不依赖该分布的旁证。

**重要**：29–30 左右的数字是代理估计，不是平台隐藏测试的实测分数。

### 3.3 最终配置

| 项 | 值 |
|---|---|
| 权重形状 | uniform，`RUL ≤ 150` |
| floor / power | 0.05 / 0.5 |
| 训练 | 从父检查点续训，30 epoch，lr 0.002，batch 256 |
| 选型 | `late_rmse`（RUL ≤ 200） |
| 全量 guard | **5%**（并列判据：全量不劣化 **且** 切片改善） |
| 特征 / 前向 / checkpoint | 完全不变，推理只需要 `inputs` |

### 3.4 10 轮离线路径

| 轮 | 假设 | 采纳 | full RMSE | late RMSE |
|---:|---|---|---:|---:|
| 1 | more-data-helps | 是 | 52.87 → 52.23 | 39.92 → 38.52 |
| 2 | the-parent-was-left-unconverged | 否 | 52.23 → 51.24 | 38.52 → 39.28 |
| 3 | **the-test-is-truncated** | **是**（旧规则 12% guard 下放行；新规则 5% 并列判据下会否决） | 52.23 → **57.42** | 38.52 → **33.91** |
| 4 | the-tail-is-underweighted | 否 | 57.42 → 55.83 | 33.91 → 34.22 |
| 5 | the-unit-is-the-confounder | 否 | 57.42 → 51.97 | 33.91 → 35.33 |
| 6 | capacity-is-overfitting | 否 | 57.42 → 51.22 | 33.91 → 38.99 |
| 7–10 | more-data-helps（重复） | 否 | 57.42 → 51.14–51.86 | 33.91 → 38.39–39.64 |

最终 production 停在 r3。

> ⚠️ 上表是**旧守门（12%）下**的离线演练轨迹，留作记录以说明缺陷成因。
> **上线版本守门为 5% 且判据为并列**，因此第 3 轮那个候选
> （全量 +9.95% > 5%）在现行规则下**会被否决**，系统不会把全量退化的
> 候选推上线。

### 3.5 最终指标

| 口径 | 官方基线 | 最终 r3 | 变化 |
|---|---:|---:|---:|
| full（全部公开验证行） | 52.87 | 57.42 | +8.6%（父模型 +9.95%，**超出 5% guard，上线版本会否决**） |
| late（RUL ≤ 195） | 39.59 | **32.85** | −17.0% |
| uniform（每台均匀抽一个截断周期） | 40.04 | **33.66** | −15.9% |
| CMAPSS proxy（公开测试 RUL 分布） | 39.90 | **28.50** | **−28.6%** |

三个种子的均值为 proxy `28.69 ± 0.26`、full `57.27 ± 0.14`。
备选 `cap250 + H150 floor 0.15` 的 proxy 为 29.18、uniform 33.46、
late 32.66、full 56.09，适合私有包截断 RUL 更长的情形。

## 4. 实验与证据

- **搜索**：104 条配置记录，覆盖先验形状、训练时域、floor、power、
  lr/epoch、逐子集先验、两阶段训练、目标截断；
  产物：`artifacts/tracks/c_weight_search.json`；
  复现：`python -m research.tracks.c_weight_sweep --help`。
- **12 折留一轴承选型口径实验**：`python -m research.tracks.c_horizon`；
  产物：`artifacts/tracks/c_horizon.json`。
  结论：所有截断切片与留出集真值**负相关**（ρ = −0.27 ~ −0.53），
  按切片选型 12/12 折选出 `cap150` 且在留出引擎上排名垫底；
  全量口径平均第 1 名、7/12 折赢基线。
- **相对退化度 α 扫描**：`research/tracks/c_alpha.py`；
  权重从绝对阈值改为 `w = 1 + α·(1 − y/u_max)` 后，
  `deg` 加权与不加权在统计上不可区分（Wilcoxon p = 0.68），
  真正的收益来自**剔除灾难性绝对阈值**与**加大 epoch 预算**。
- **epoch 预算实验**：`research/tracks/c_epochs.py`；
  40 epoch 赢基线 10/12 折（p = 0.0024），80 epoch 赢 11/12 折（p = 0.034），
  而 15 epoch 只有 5/12；最终取 32–75（C 的缩放系数 0.5）。
- **10 轮离线演练**：`tools/run_harness_offline.py --datasets A B C --rounds 10`；
  产物：`runs/harness-offline/{run_report.json,ledger.jsonl,swanlab/}`。
  结果：A 0.7140 → **0.7410**；B 681.16 → **456.42**；
  C 52.8686 → **51.3422**（第 10 轮 50.6314）。
- **测试**：389 passed，17 skipped；本地 CI 9/9 PASS。
- **镜像**：通过 `describe`、离线 `train`/`predict` 路径验证，无模型权重；
  镜像内 28 个 `.py` 文件与仓库提交 `25f061e` 逐字节哈希全等（0 差异）。

## 7. 已知限制

1. 代理 RMSE 依赖“私有包截断分布与公开 C-MAPSS 接近”的假设；真实隐藏
   RMSE 只能由平台给出。
2. **上线版本不再接受全量退化**。旧版曾把「正式评分只看隐藏测试 RMSE」
   当成主动取舍，推出了全量 57.42 的候选。现已改为 5% 并列守门，
   全量退化的候选一律否决。
   > 但 2026-11-23 实测说明：C 方向不达标的主因不是守门，而是
   > **公开集 → 隐藏集 +10.06% 的系统性偏移**（公开 51.11116 → 隐藏 56.25329）。
   > 这是下一版要解决的主要问题。
3. **并列判据会误杀「全量也变好」的候选**。平台公开集上
   `late_rmse` 与 `full rmse` 频繁反向：第 2 轮全量好了 1.05、
   第 7 轮全量是十轮最好的 50.8784，都因为切片小幅变差被否决，
   最终停在第 5 轮（51.1112）。并列判据的容差需要重新标定。
4. 私有包是另一批同领域数据；若截断 RUL 明显长于公开 C-MAPSS，备选
   `cap250 + H150 floor 0.15`（proxy 29.18，full 56.09）更稳。
5. 离线演练的模型请求部分由本地替身作答；它证明代码路径，不证明平台分数。
   真实 27B 驱动的 30 轮演练记录见 `runs/harness-offline/run_report.json`；
   平台逐轮记录见 `docs/PLATFORM_RUN_20261123_ANALYSIS.md`。
