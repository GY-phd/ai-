## 三、数据使用边界

1. **仅使用赛题提供的官方数据包**（公开训练集与验证集）。
2. **未获取、未尝试获取隐藏测试集或其标签**。代码中不存在读取隐藏集的
   路径：系统只通过 `rnd.data.train_path` 与 `rnd.data.validation_path`
   读取公开投影。
3. **未对评测平台发起攻击、未使用违规手段**。
4. 合成训练样本（100 条策略合成 + 180 条平衡反事实）是**在真实字段空间上
   由确定性策略生成**的本地数据，用于策略层 LoRA，**不是线上测量结果**；
   训练报告按 `real` / `policy` / `balanced` 分开统计，报告中如实区分。
5. PyTRiO API Key **仅填写在评测平台表单的密钥栏**，未写入仓库、镜像、
   文档或本声明。
